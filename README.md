# Postal Cove

Окружение для будущей интерактивной HTML-презентации Postal Cove.

## Структура

Будущая стартовая страница — `index.html` в корне. Стили и скрипты также можно разместить в корне; изображения, звук и видео — в `media/`, дополнительные публичные материалы — в `docs/`.

Страница пока не добавлена. Зависимости и сборка не требуются.

## Локальный просмотр

Из папки репозитория:

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

После добавления страницы открыть `http://127.0.0.1:8768/index.html`.

## Публикация

Основная ветка — `main`. В корне есть `.nojekyll` для статических файлов. GitHub Pages и автоматическое развёртывание пока не настроены. Их можно включить после подготовки и проверки страницы.

В репозиторий входят только материалы презентации. Unity-проект, рабочие заметки и промежуточные документы хранятся отдельно. Лицензии добавляются вместе с соответствующими сторонними материалами.
