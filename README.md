# Postal Cove — Свет для бухты

Играбельная островная локация и описание её дизайна: сеттинг, сюжет, квесты, схема маршрута и логика расстановки.

Автор: Vlad Pinchuk · [LinkedIn](https://www.linkedin.com/in/vlad-pinchuk)

[Прохождение](https://youtu.be/bBDQV3LwVJs)

Статическая страница находится в `index.html`. Для локального просмотра запустите `python3 -m http.server 8768` и откройте `http://127.0.0.1:8768/`.
